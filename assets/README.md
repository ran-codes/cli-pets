# Assets

This directory contains images and GIFs used in the project README.

## Files

- `demo.gif` - Main demo animation showing CLI pets in action

## Creating a Demo GIF

You can use tools like:
- **asciinema** - Record terminal sessions: https://asciinema.org/
- **terminalizer** - Record and render terminal sessions: https://terminalizer.com/
- **ttygif** - Convert terminal recordings to GIF
- **peek** - Simple screen recorder for Linux

Example with asciinema:
```bash
# Record
asciinema rec demo.cast

# Convert to GIF using agg or gif tools
```
